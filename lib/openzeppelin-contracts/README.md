# OpenZeppelin Contracts dependency subset

Unmodified Solidity dependencies reachable from SqueekSupplyBoard, copied from
the locked npm package `@openzeppelin/contracts@5.6.1`. Included for IMD's offline
Foundry build. License: MIT, see LICENSE. Source files retain upstream SPDX headers.

Upstream: https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.6.1

This directory is not a separate repository or submodule. Dependency updates must
update package-lock.json and this subset together, then rerun contract tests.
